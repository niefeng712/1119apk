# 福彩体彩助手（Android · Jetpack Compose）

手机与 9–14 寸平板自适应的开奖查询 App，字号偏大、适合长辈使用。

## 票种
| 票种 | 机构 | 开奖时间 | 号码 |
| --- | --- | --- | --- |
| 福彩3D | 中国福彩 | 每日 21:15 | 3 位数字 |
| 排列三 | 中国体彩 | 每日 21:25 | 3 位数字 |
| 排列五 | 中国体彩 | 每日 21:25 | 5 位数字 |
| 超级大乐透 | 中国体彩 | 每周一、三、六 21:25 | 前区 35 选 5 + 后区 12 选 2 |

## 功能
- **开奖大厅**：顶部概览卡显示今日开奖票种与进度；每个票种卡片显示最新一期号码、奖池、开奖状态（今晚开奖 / 今日已开奖 / 今日不开奖）。
- **双通道同步**：官方接口（福彩网 / 体彩网）+ 新浪开奖页快讯。开奖窗口（21:14–21:40）新浪每 8 秒刷新，官方接口约 30 秒补一次奖级明细；新浪快讯不会覆盖同一期的官方完整数据。
- **省电轮询**：白天 5 分钟、21 点后 1 分钟、开奖窗口 8 秒；当天所有票种开完或不开奖即停止。后台 WorkManager 每 15 分钟兜底同步。
- **历史开奖**：每页 100 期，可加载更多，可按期号/日期筛选；平板横屏为左右分栏详情。
- **看直播**：福彩 / 体彩官方直播与新浪往期回放。
- **自动更新**：启动时检查 GitHub Releases 最新版本并下载安装。

## 构建
推送到 `main` 后 GitHub Actions 自动构建 Debug APK（固定签名），发布到 Releases 并清理旧版本。
