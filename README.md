# 福彩体彩资讯与走势 APK 工程（全彩种 + 9寸–14寸平板自适应版）

## 本次升级内容
1. **覆盖中国福彩与体彩全部主流玩法（8大彩种）**：
   - **中国福彩**：双色球、快乐8、福彩3D、七乐彩
   - **中国体彩**：超级大乐透、排列三、排列五、七星彩
2. **开奖大厅直达历史开奖**：
   - 每个彩种卡片旁均有「历史开奖」「走势图」「看直播」快捷按钮，点击「历史开奖」直接进入该彩种近 100 期（支持翻页加载更多）开奖列表，无需手动输入期号即可浏览。
3. **开奖直播纯净全屏体验**：
   - 点击直播直接进入官方直播画面，移除手动流地址输入框；
   - 修复网页内视频与全屏切换白屏问题（保持 WebView 单例不重建，并将 HTML5 视频全屏视图挂载至 Activity 顶层 DecorView，支持 `window.open`/往期开奖视频同窗口播放与第三方 Cookie）。
4. **走势图数据扩容与排版优化**：
   - 默认拉取近 100 期历史数据，使用 `LazyColumn` + 统一横向滚动容器解决大期数与多列截断问题；
   - 支持双色球/大乐透/七乐彩红蓝球切换、数字彩（福彩3D/排列三/排列五/七星彩）按位走势连线。
